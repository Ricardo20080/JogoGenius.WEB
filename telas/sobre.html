Sobre o Projeto

O Genius é um jogo de memória desenvolvido com HTML, CSS e JavaScript. O objetivo é testar a atenção do jogador através de sequências de cores que aumentam a cada rodada.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • LocalStorage
  • DOM Manipulation

Objetivo

Repetir corretamente a sequência de cores gerada pelo sistema, que aumenta progressivamente a dificuldade a cada rodada.
