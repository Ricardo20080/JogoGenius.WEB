# 🧠 Genius Game (HTML, CSS e JavaScript)

## 📌 Descrição do projeto

Este projeto é uma implementação do jogo clássico **Genius** utilizando tecnologias web: **HTML, CSS e JavaScript puro**.

O jogo tem como objetivo testar a memória do jogador, que deve repetir corretamente uma sequência de cores gerada automaticamente pelo sistema. A cada rodada, a sequência aumenta, tornando o jogo progressivamente mais difícil.

O projeto foi desenvolvido com fins educacionais para praticar lógica de programação, manipulação do DOM, eventos e estruturas de dados em JavaScript.

---

## 🚀 Como funciona

O jogo funciona totalmente no navegador (executado em ambiente local/localhost ou hospedado), utilizando JavaScript para controlar toda a lógica.

### 🔁 Fluxo geral:
- O sistema gera uma sequência aleatória de cores.
- O jogador deve repetir a sequência corretamente.
- A cada acerto, a sequência aumenta.
- Em caso de erro, o jogo é finalizado.
- O recorde é salvo no navegador (localStorage).

---

## 🧠 Tecnologias utilizadas

- HTML5 → estrutura da interface
- CSS3 → estilos e efeitos visuais
- JavaScript → lógica do jogo e interatividade
- LocalStorage → armazenamento de recorde
